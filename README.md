# 3D-прототип

Прототип платформера на Babylon.js, TypeScript и Vite. Перепрыгните через провалы и доберитесь до зелёного маяка. После падения робот возвращается на старт.

## Локальный запуск

Понадобится Node.js с npm. Из папки проекта выполните:

```powershell
npm ci
npm run dev
```

Откройте адрес, который напечатает Vite. Чтобы остановить сервер, нажмите **Ctrl+C** в терминале.

Для проверки на телефоне в той же сети запустите `npm run dev -- --host` и откройте адрес **Network**, который напечатает Vite.

## Управление

- **Клавиатура** — WASD или стрелки для движения, пробел для прыжка, R для перезапуска.
- **Сенсорный экран** — виртуальный стик слева и кнопка прыжка справа. Их можно нажимать одновременно.
- Движение задаётся относительно камеры. При движении камера доворачивается за роботом, а на месте сохраняет угол.
- **Заново** возвращает робота на старт в любой момент.
- **⛶** переключает полноэкранный режим, если его поддерживает браузер. На iPhone откройте игру в Safari, выберите **Поделиться → На экран «Домой»** и запустите игру с добавленного значка.

## Код

- `src/main.ts` — запуск движка и изменение размера canvas.
- `src/scene.ts` — трасса, камера, освещение и загрузка модели.
- `src/platformer.ts` — гравитация, прыжок и столкновения с платформами.
- `src/input.ts` — клавиатура и сенсорное управление.
- `src/assets/floor.png` — повторяемая текстура пола.
- `src/assets/scout-robot.glb` — тестовая модель робота.
- `src/assets/krea-crate.glb` — декоративный ящик с текстурами, сгенерированный в Krea.

`npm run build` проверяет типы и собирает версию для статического хостинга в `dist/`. `npm run preview` запускает локальный просмотр этой сборки.
