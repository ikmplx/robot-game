# Рубеж

3D-прототип на Babylon.js, TypeScript и Vite. Маленький робот начинает на полу большой комнаты. Перепрыгните опасный участок по четырём широким кубам, победите монстров и толкните два ящика нижнего склада прямо по цветным меткам.

Первый лифт ведёт на полку с монстрами. Оттуда переправьтесь по тросу к лифту на второй этаж. Там вас ждут пять более узких платформ разной высоты, монстры и четыре ящика. Обойдите перегородки и расставьте ящики на площадки с совпадающим цветом и числом полос. Второй трос ведёт к двери с кошачьей мозаикой.

Монеты показывают маршрут. Над каждым кубиком в обоих участках с прыжками висит одна монета. На складах цветной пунктир ведёт каждый ящик к его метке. В меню «Уроки» каждая кнопка «Зачесть» один раз выдаёт звезду. Соберите три звезды, чтобы открыть у двери мозаику из восьми плиток. Выбирайте две плитки мышью, касанием или клавиатурой, чтобы поменять их местами. Когда картинка собрана, дверь открывается.

За дверью начинается Свечной зал. Свет плавно гаснет, а большая свеча у входа уже горит и освещает первую часть коридора. Ударами меча зажигайте видимые свечи и выбирайте путь на развилках. Проход к арене открыт с самого начала. Хранитель чередует удар по площади с рывком. Уклоняйтесь от отмеченных на полу атак, бейте по бирюзовому ядру и откройте сундук за ареной, чтобы получить 25 монет.

Опасный пол, падение с платформы и потеря здоровья возвращают к последней контрольной точке. Кнопка «Чекпоинты» открывает список всех контрольных точек. Выбранный участок и всё после него начнутся заново, а собранные монеты и звёзды сохранятся. Кнопка «Сбросить ящики» возвращает на место ящики текущего склада. «Заново» сбрасывает весь уровень и прогресс.

## Локальный запуск

```powershell
npm ci
npm run dev
```

Откройте адрес, который напечатает Vite. Для проверки на телефоне в той же сети запустите `npm run dev -- --host` и откройте адрес **Network**.

## Управление

| Действие | Клавиатура и мышь | Геймпад Xbox | Сенсорный экран |
| --- | --- | --- | --- |
| Движение и толкание ящиков | WASD или стрелки | Левый стик | Стик |
| Прыжок | Пробел | A | «Прыжок» |
| Удар | Левая кнопка мыши | X | «Удар» |
| Лифт, трос и взаимодействие | E или кнопка на экране | Y | Кнопка на экране |
| Начать заново | R | Menu | ↻ |

`npm run build` проверяет типы и собирает статическую версию в `dist/`. `npm run preview` запускает её локально.

## GitHub Pages

Сайт проекта обслуживается из ветки `gh-pages`. Для обновления опубликуйте содержимое `dist/` в корне этой ветки. Сборка использует относительные пути и работает в подкаталоге проекта. Для репозиториев с источником GitHub Actions также доступен workflow `pages.yml`.
