# Рубеж

3D-прототип на Babylon.js, TypeScript и Vite. Юный искатель с красной пандой на плече начинает в ночной библиотеке. Перепрыгните опасный участок по четырём широким кубам, победите бумажных журавликов и толкните два ящика нижнего склада прямо по цветным меткам.

Первый лифт ведёт на полку с журавликами. Оттуда переправьтесь по тросу к лифту на второй этаж. Там вас ждут пять более узких платформ разной высоты, бумажные журавлики и четыре ящика. Обойдите перегородки и расставьте ящики на площадки с совпадающим цветом и числом полос. Второй трос ведёт к двери с кошачьей мозаикой.

Монеты показывают маршрут. Над каждым кубиком в обоих участках с прыжками висит одна монета. На складах цветной пунктир ведёт каждый ящик к его метке. В меню «Уроки» каждая кнопка «Зачесть» один раз выдаёт звезду. Соберите три звезды, чтобы открыть у двери мозаику из восьми плиток. Выбирайте две плитки мышью, касанием или клавиатурой, чтобы поменять их местами. Когда картинка собрана, дверь открывается.

В левой комнате нижнего склада лежат пять монет. Библиотекарь в правой комнате рассказывает, почему замок Химэдзи прозвали замком Белой цапли, и выдаёт карточку. Откройте её через «Дневник» в верхнем меню. Карточка сохраняется в браузере между запусками игры. [Фото замка — Drivephotographer, CC0](https://commons.wikimedia.org/wiki/File:Himeji_castle.jpg).

За дверью начинается Свечной зал. Свет плавно гаснет, а большая свеча у входа уже горит и освещает первую часть коридора. Ударами меча зажигайте видимые свечи и выбирайте путь на развилках. Проход к арене открыт с самого начала. Хранитель, большой кот-призрак, чередует удар по площади с рывком. Уклоняйтесь от отмеченных на полу атак, бейте по бирюзовому ядру и откройте сундук за ареной, чтобы получить 25 монет.

Опасный пол, падение с платформы и потеря здоровья возвращают к последней контрольной точке. Кнопка «Чекпоинты» открывает список всех контрольных точек. Выбранный участок и всё после него начнутся заново, а собранные монеты и звёзды сохранятся. Кнопка «Сбросить ящики» возвращает на место ящики текущего склада. «Заново» сбрасывает уровень, монеты и звёзды.

## Локальный запуск

```powershell
npm ci
npm run dev
```

Откройте адрес, который напечатает Vite. Для проверки на телефоне в той же сети запустите `npm run dev -- --host` и откройте адрес **Network**.

## Управление

| Действие | Клавиатура и мышь | Геймпад Xbox | Сенсорный экран |
| --- | --- | --- | --- |
| Движение и толкание ящиков | WASD или стрелки | Левый стик | Стик |
| Прыжок | Пробел | A | «Прыжок» |
| Удар | Левая кнопка мыши | X | «Удар» |
| Лифт, трос и взаимодействие | E или кнопка на экране | Y | Кнопка на экране |
| Начать заново | R | Menu | ↻ |

`npm run build` проверяет типы и собирает статическую версию в `dist/`. `npm run preview` запускает её локально.

## GitHub Pages

GitHub Pages обслуживает обе версии из ветки `gh-pages`. Запускайте команды из локальной рабочей копии с настроенным доступом к `origin`.

| Версия | Адрес | Команда публикации |
| --- | --- | --- |
| Для показа | https://ikmplx.github.io/robot-game/ | `npm run deploy:stable` |
| Для разработки | https://ikmplx.github.io/robot-game/dev/ | `npm run deploy:dev` |

Команды собирают текущие локальные файлы. Dev-публикация обновляет только сборку в `dev/`, а выпуск стабильной версии обновляет сборку в корне и сохраняет `dev/`. Для показа публикуйте стабильную версию после проверки изменений на dev-адресе.
