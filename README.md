# Рубеж

3D-прототип на Babylon.js, TypeScript и Vite. Маленький робот начинает на полу большой комнаты. Перепрыгните опасный участок по четырём широким кубам, победите монстров и толкните два ящика нижнего склада прямо по цветным меткам.

Первый лифт ведёт на полку с монстрами. Оттуда переправьтесь по тросу к лифту на второй этаж. Там вас ждут пять более узких платформ разной высоты, монстры и четыре ящика. Обойдите перегородки и расставьте ящики на площадки с совпадающим цветом и числом полос. Второй трос ведёт к двери с кошачьей мозаикой.

Монеты показывают маршрут. В меню «Уроки» каждая кнопка «Зачесть» один раз выдаёт звезду. Соберите три звезды, чтобы открыть у двери мозаику из восьми плиток. Выбирайте две плитки мышью, касанием или клавиатурой, чтобы поменять их местами. Когда картинка собрана, дверь открывается.

За дверью начинается Свечной зал. В лабиринте видны только проходы около зажжённых свечей. Первая большая свеча стоит прямо у входа. Зажигайте большие и малые свечи ударами меча. Четыре большие свечи открывают решётку. За ней Хранитель чередует удар по площади с рывком. Уклоняйтесь от отмеченных на полу атак, бейте по бирюзовому ядру и откройте сундук за ареной, чтобы получить 25 монет.

Опасный пол, падение с платформы и потеря здоровья возвращают к последней контрольной точке. Кнопка «Сбросить ящики» возвращает на место ящики текущего склада. «Заново» сбрасывает весь уровень и прогресс.

## Локальный запуск

```powershell
npm ci
npm run dev
```

Откройте адрес, который напечатает Vite. Для проверки на телефоне в той же сети запустите `npm run dev -- --host` и откройте адрес **Network**.

## Управление

| Действие | Клавиатура и мышь | Геймпад Xbox | Сенсорный экран |
| --- | --- | --- | --- |
| Движение и толкание ящиков | WASD или стрелки | Левый стик | Стик |
| Прыжок | Пробел | A | «Прыжок» |
| Удар | Левая кнопка мыши | X | «Удар» |
| Лифт, трос и взаимодействие | E или кнопка на экране | Y | Кнопка на экране |
| Начать заново | R | Menu | ↻ |

`npm run build` проверяет типы и собирает статическую версию в `dist/`. `npm run preview` запускает её локально.

## GitHub Pages

В настройках Pages выберите GitHub Actions как источник. Публикация запускается при push в основную ветку репозитория. Сборка использует относительные пути и работает в подкаталоге проекта.
