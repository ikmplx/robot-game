# 3D-прототип

Стартовая сцена на Babylon.js, TypeScript и Vite. Комната и платформы собраны из примитивов. Пол использует локальную текстуру, а робот на средней платформе загружается из файла GLB.

## Локальный запуск

Понадобится Node.js с npm. Из папки проекта выполните:

```powershell
npm ci
npm run dev
```

Откройте адрес, который напечатает Vite. Перетаскивайте сцену мышью или пальцем, чтобы повернуть камеру. Колесо мыши и жест двумя пальцами меняют масштаб. Чтобы остановить сервер, нажмите **Ctrl+C** в терминале.

Для проверки на телефоне в той же сети запустите `npm run dev -- --host` и откройте адрес **Network**, который напечатает Vite.

## Код

- `src/main.ts` — запуск движка и изменение размера canvas.
- `src/scene.ts` — геометрия, камера, освещение и загрузка модели.
- `src/assets/floor.png` — повторяемая текстура пола.
- `src/assets/scout-robot.glb` — тестовая модель робота.

`npm run build` проверяет типы и собирает версию для статического хостинга в `dist/`. `npm run preview` запускает локальный просмотр этой сборки.
