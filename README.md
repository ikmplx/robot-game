# Рубеж

Одноуровневый 3D-прототип на Babylon.js, TypeScript и Vite. Маленький робот начинает на полу большой комнаты. Перепрыгните опасный участок по кубам, победите монстров и толкните два подвижных куба на метки соответствующих цветов. Это откроет путь к лифту. На полке вас ждёт второй бой и дверь.

Монеты показывают маршрут. В меню «Уроки» каждая кнопка «Зачесть» один раз выдаёт звезду. Соберите три звезды, чтобы запустить заглушку мини-игры у двери и открыть проход к выходу.

Опасный пол и потеря здоровья возвращают к последней контрольной точке. В головоломке кнопка «Сбросить кубы» позволяет начать расстановку заново. «Заново» сбрасывает весь уровень и прогресс.

## Локальный запуск

```powershell
npm ci
npm run dev
```

Откройте адрес, который напечатает Vite. Для проверки на телефоне в той же сети запустите `npm run dev -- --host` и откройте адрес **Network**.

## Управление

| Действие | Клавиатура и мышь | Геймпад Xbox | Сенсорный экран |
| --- | --- | --- | --- |
| Движение и толкание кубов | WASD или стрелки | Левый стик | Стик |
| Прыжок | Пробел | A | «Прыжок» |
| Удар | Левая кнопка мыши | X | «Удар» |
| Взаимодействие | E или кнопка на экране | Y | Кнопка на экране |
| Начать заново | R | Menu | ↻ |

`npm run build` проверяет типы и собирает статическую версию в `dist/`. `npm run preview` запускает её локально.
